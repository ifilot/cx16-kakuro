# Graphics and memory
Display: 640x480 pixels at native scaling.
Backgrounds: 2 bits per pixel, four palette colors.
Board: 4-bit tiles, 16x16 pixels; four tiles per cell.
Video RAM: 128 KiB VERA.
Required system RAM: 512 KiB for the journal caches.

# Game data
96 puzzles, with boards from 6x6 to 10x10.
Puzzle sources: assets/puzzles/*.puz
Game data is compiled into PUZZLE.DAT.
Opened and solved status is stored in that file.

# Audio
Playback library: ZSMKit.
Music streams from MENU.ZSM and GAME.ZSM.
18 effects are loaded from SFX.BIN.
Music: priority 0, PSG voices 0-9.
Effects: priority 1, PSG voices 12-15.
