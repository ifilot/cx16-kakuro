# Kakuro audio

These files were generated by the neighboring `cx16-sound-generator` project
from `assets/kakuro/project.yaml`. They replace the previous music and tile effect.

- `MENU.ZSM`: **Niwa**, 83.2 seconds; loops after its 6.4-second intro. Used
  on the start screen, journal, Options, Help and About.
- `GAME.ZSM`: **Quiet Grid**, 112 seconds; loops during puzzles.
- `SFX.BIN`: 18 headerless, concatenated ZSM effects.
- `sfx.h`: generated offsets for navigation, digits 1–9, checking, wrong
  entries, dialogs and the solved jingle. Keep this header with its matching blob.

Music uses priority 0 and PSG voices 0–9. Effects use priority 1 and voices
12–15, play once and remain available when Music is off. Both priorities use
zero attenuation, matching the generator's mix. Hovering stays silent;
keyboard card movement clicks, activation selects, page changes turn a page,
and erasing or returning uses the Back effect. Wrong-entry feedback sounds
only when a digit is entered with Check enabled. Redrawing never triggers it.

Effects reside at `$B000` in RAM bank 4 (3,110 bytes). The generated offsets
are independent of the actual load address: the game relocates the blob from
its suggested `$A000` to `$B000`, leaving legacy color-swap scratch at
`$A000–$AFFF` and all journal caches intact. Music streams from disk through
ZSMKit's buffers in bank 1. The game services buffers even when music is muted.

To update the bundle, build it in the generator first, then copy these four
matching outputs from this repository's root:

```bash
(cd ../cx16-sound-generator && ./x16snd project assets/kakuro/project.yaml)
cp ../cx16-sound-generator/build/kakuro/{MENU.ZSM,GAME.ZSM,SFX.BIN,sfx.h} assets/sound/
make
python3 tests/check_audio.py
```

The game builds from its own copy of the assets, so distributing or building
it does not require the sound generator. The audio test exercises the linked
game audio routines in the emulator and compares PSG register changes with
the generated streams, including every effect, looping, mute and scene changes.
